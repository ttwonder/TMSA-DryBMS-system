一次性初始化碼 · 離線工具

僅供新的專用 TMSA／DRYBMS Supabase 專案。先安裝 001_platform.sql 並完成唯讀核驗；未核對正式目標前，不要執行下方 SQL。此工具不連網、不執行 SQL、不發布網站。

只有按下按鈕後才會在本機產生碼。它不是 Owner 密碼或進站密碼；Owner 建立後即失效。不要貼到聊天、Git 或公開網頁。

尚未產生。

1. 私有設定 SQL

在已核對的 Supabase SQL Editor 新建一個 query；全選下方內容，自行 Ctrl+C、貼上並 Run 一次。這會設定初始化權限，但不會建立 Owner 或匯入資料。

2. 保管並使用一次性碼

先存到自己的密碼管理器，再在網站的「初始化 Owner」畫面輸入這個碼。Owner 名稱、帳號、Owner 密碼及進站密碼由你自行設定。

選取按鈕只選文字，不使用剪貼簿 API。請先顯示碼再 Ctrl+C。關閉／重載此頁會丟失尚未保管的碼；此頁不使用 localStorage 或 sessionStorage。若設定 SQL 已執行，不要重新產生或重跑設定來猜測結果；先核對是否已建立 Owner。
